[ SIG.03 · CORE ]

Three design questions at the core.

01 / PLANNER

Can an operator inspect the plan?

The concept separates the goal, proposed steps and expected outcome. An operator should be able to inspect that proposal before authorizing a consequential action. The planner visualization is illustrative.

02 / ROUTER

Where does the time budget go?

The sub-40ms hand-off is a hypothetical budget for one orchestration step, not a measured result or an end-to-end agent response time. The latency note separates local routing, network waits and external execution.

03 / LEDGER

Can someone explain the outcome?

A useful audit record would identify the actor, proposed action, policy decision and observed result. This study shows the shape of that record; tamper resistance, storage and enforcement would need a real backend.

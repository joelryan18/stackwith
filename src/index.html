A small workshop can move quickly without becoming careless. Each stage leaves behind something concrete and reviewable.

    Frame

  2. 02

    System + prototype
  3. 03

    Engineer

    Turn the approved direction into maintainable browser software with real data and explicit fallbacks.

    Working product
  4. 04

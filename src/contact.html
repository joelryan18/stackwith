Contact Joel Ryan.

Messages go to the person who built and writes stackwith.me. Joel Ryan designs, codes, tests, and documents every project on this domain — so enquiries about the work, the engineering notes, or the design decisions land with the person who made them.

  • Projects & field notes — hello@stackwith.me
  • Supporter-pass questions — support@stackwith.me
  • Press & collaborations — press@stackwith.me
  • Privacy requests — privacy@stackwith.me (see our Privacy Policy)
  • Legal — legal@stackwith.me
  • Security disclosures — security@stackwith.me — please include reproduction steps and affected URLs.

Good questions to send

The work on this site is deliberately documented so readers can evaluate it without relying on marketing claims. If you have found something unclear, undocumented, or worth discussing, that is exactly the kind of message worth sending:

  • Questions about how a specific part of a browser project was built — the engineering notes point back to real decisions, and the source is in the repository.
  • Feedback on a field note: something that was omitted, a measured limit that does not match your own findings, or an approach you have taken differently.
  • Design observations about the AXON interface study — the showcase is meant to be evaluated, not just viewed.
  • Accessibility issues on any page — reproduced with device type and browser version, if possible.

What to expect

stackwith.me is maintained by one person, not a staffed support organisation. Responses to genuine technical questions usually come within a few days; high-volume periods may push that to a week or more. Clear reproduction steps, page URLs, browser details, and screenshots make technical questions much easier to answer.

There is no public phone-support line and no round-the-clock coverage. Email is the clearest route because it creates a useful paper trail for technical and privacy requests.

About the workshop

stackwith.me is Joel Ryan's one-person software workshop: working browser projects, a transparently labelled agent-interface design showcase, and first-hand engineering notes that explain how the code is built. Every project is documented to the point where a reader can verify the claims being made. Working code is always distinguished from design targets.

The site publishes at https://stackwith.me via GitHub Pages and has been running continuously since 2024.
